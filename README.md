# Faserli
Faserli: a local AI assistant that explains and fixes C++ errors. A QLoRA-fine-tuned Qwen2.5-Coder-7B (via Ollama) reads your code through MCP tools, explains the cause, proposes a corrected file, checks it by compiling in a sandbox, and applies it in one click. FastAPI web UI, runs fully offline on your PC.
